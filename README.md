# Robot Builder Clicker
⭐INSTRUCTIONS⭐
Start from a battery, and get up to a full-sized robot mech!! Click the battery to receive 1 power. Every 100 power your robot will upgrade. Try to make it to 500 for the ultimate robot mech!
-------------------------------------------------------------------------
⭐LORE⭐
Once upon a time, one man found a PKCell AAA Ultra Heavy Duty battery laying on the sidewalk, outside, in the rain. When he brought it home, he ran it in a battery tester. The results: It was an unused battery. He decided "well, I've got thousands of robot parts around here. All I'm missing is a battery!" He clicked on Robot Builder Clicker 100 times. Once he reached the robot stage, the robot came to life!! The man was scared and ran far away from home. He then got eaten by a bear. Now, your goal is to replace the man and build a robot! Can you do it?
-------------------------------------------------------------------------
To download:
Download the latest release, extract the zip file, and run Robot Builder Clicker.exe. No install required. The game will begin in fullscreen. To exit fullscreen, press Escape. To exit the game, press Escape again.
