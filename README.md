# ⭐INSTRUCTIONS⭐
Start from a battery, and get up to a full-sized robot mech!! Click the battery to receive 1 power. Every 100 power your robot will upgrade. Try to make it to 500 for the ultimate robot mech!
# ⭐LORE⭐
Once upon a time, one man found a PKCell AAA Ultra Heavy Duty battery laying on the sidewalk, outside, in the rain. When he brought it home, he ran it in a battery tester. The results: It was an unused battery. He decided "well, I've got thousands of robot parts around here. All I'm missing is a battery!" He clicked on Robot Builder Clicker 100 times. Once he reached the robot stage, the robot came to life!! The man was scared and ran far away from home. He then got eaten by a bear. Now, your goal is to replace the man and build a robot! Can you do it?

# To download:
Download the latest release, extract the zip file, and run Robot Builder Clicker.exe. No install required. The game will begin in fullscreen. To exit fullscreen, press Escape. To exit the game, press Escape again. All of my games are also available on Itch. There is a link on my profile if you would like to learn more.

# Want to make a fork?
If you want to make a fork, feel free to fork the project. If you fork, please make some sort of change. To make a change, download the sb3 file from the latest release, load it into the Scratch offline or online editor, make the edits, save it to a new file, then upload the new file to TurboWarp Packager. To add the assets, rename the .sb3 to .zip and add everything inside to the assets.
